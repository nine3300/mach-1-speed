### Main Configuration

- `pnpm lint` - Run linting
- `pnpm lint:fix` - Auto-fix lint errors
- `pnpm typecheck` - TypeScript type checking
- `pnpm format` - Format with Prettier
- `pnpm precheck` - All checks combined
